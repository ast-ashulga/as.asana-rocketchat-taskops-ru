# as.asana-rocketchat-taskops-ru

Документация по внедрению интеграции **Rocket.Chat ↔ Asana** для приёма запросов в чатах, создания задач в Asana и проактивного контроля выполнения с **Asana Intelligence / AI Teammates** и интеграционным слоем **n8n**, дополненная “умным Intake” через **Rocket.Chat AI (AI API, под капотом)** — **без нового пользовательского UI**.

### О чём этот репозиторий

Это пример методологии внедрения ИИ в рабочие процессы организации, один из кирпичиков AI-native компании. На конкретном процессе (приём запросов из чатов, постановка задач и контроль их выполнения) показано, как встроить ИИ в инструменты, которыми команда уже пользуется, не меняя привычный UI и оставляя ключевые решения за человеком.

В репозитории есть всё, что нужно для внедрения:

- **зачем**: продуктовая история с болями и выгодами для каждой роли;
- **что**: архитектура решения и границы ответственности ИИ;
- **как**: пошаговый план внедрения с критериями готовности, настройкой Asana, Rocket.Chat и n8n, тестированием и раскаткой;
- **где может сломаться**: риски, anti-spam и сценарии отказов.

### Принципы (кратко)

- **Human-in-the-loop**: AI предлагает/анализирует, решения по критическим полям принимает PM.
- **Идемпотентность и anti-spam**: один запрос → одна задача; уведомления в Rocket.Chat — только по важным событиям и с кулдаунами.
- **AI — “под капотом”**: Rocket.Chat AI используется для intent/extraction/контекста/подсказок по дублям; критические решения остаются за PM и фиксируются в Asana.
