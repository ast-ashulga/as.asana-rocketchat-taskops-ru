# as.asana-rocketchat-taskops-ru

Документация по внедрению интеграции **Rocket.Chat ↔ Asana** для приёма запросов в чатах, создания задач в Asana и проактивного контроля выполнения с **Asana Intelligence / AI Teammates** и интеграционным слоем **n8n**, дополненная “умным Intake” через **Rocket.Chat AI (AI API, под капотом)** — **без нового пользовательского UI**.

### Start here

- **Пошаговое внедрение (главный вход)**: `implementation/README.md`
- **Архитектура и “Asana-native” концепция**: `solution_nocode_teammate.md`
- **Продуктовая история/ценность для ролей**: `product_story.md`
- **Заметки по улучшениям (исследование Rocket.Chat AI)**: `AI_IMPROVEMENTS_REVIEW.md`

### Принципы (кратко)

- **Human-in-the-loop**: AI предлагает/анализирует, решения по критическим полям принимает PM.
- **Идемпотентность и anti-spam**: один запрос → одна задача; уведомления в Rocket.Chat — только по важным событиям и с кулдаунами.
- **AI — “под капотом”**: Rocket.Chat AI используется для intent/extraction/контекста/подсказок по дублям; критические решения остаются за PM и фиксируются в Asana.
