# 02. Настройка Asana (проект Inbox, поля, правила, Teammate)

Цель: подготовить в Asana “входную воронку” для всех запросов из Rocket.Chat и сделать так, чтобы PM мог быстро:

- привести задачу к стандарту (с помощью Teammate)
- подтвердить критические поля (human‑in‑the‑loop)
- контролировать риски и дедлайны

---

## 1) Подготовка: что нужно заранее

- Права на создание проектов и кастомных полей в Asana.
- Решения из `01_prerequisites_and_decisions.md`:
  - название проекта Inbox
  - список секций
  - набор кастомных полей
  - политика “Blocked”

---

## 2) Создайте входной проект “Inbox from Rocket.Chat”

### Шаги
1) В Asana нажмите **Create → Project**.
2) Название: **Inbox from Rocket.Chat**.
3) Тип: список/board — выберите то, что привычнее PM (ниже инструкции для обоих).
4) Доступ:
   - PM(ы): полный доступ (редактирование)
   - Исполнители: доступ по необходимости (обычно видят задачи, где они назначены)
   - Инициаторы: обычно не добавляются в проект (они видят статусы через Rocket.Chat).

### Секции
Создайте секции:
- `New`
- `Triaged`
- `In Progress`
- `Done`

Рекомендация: на старте держите процесс простым — минимум секций, минимум правил.

---

## 3) Добавьте кастомные поля (минимальный набор)

Создайте (или переиспользуйте существующие) кастомные поля:

### Обязательные
- `Source` (Dropdown)
  - значение: `Rocket.Chat`
- `Rocket.Chat Link` (Text)
  - будет хранить ссылку на тред/сообщение

### Рекомендуемые
- `Priority` (Dropdown)
  - пример значений: `P0`, `P1`, `P2`, `P3` (или `High/Medium/Low`)
- `Type` (Dropdown)
  - пример значений: `Bug`, `Request`, `Question`, `Ops`, `Other`

### Опционально (если выбрали вариант “Blocked через поле”)
- `Blocked` (Checkbox или Dropdown Yes/No)

### Опционально (если хотите автоматическую синхронизацию статусов PM → Rocket.Chat)
Если вы хотите, чтобы n8n **сам публиковал** в тред Rocket.Chat решения PM (“нужны уточнения/отклонено/подтверждено”), добавьте одно поле:

- `PM Decision` (Dropdown)
  - пример значений: `Draft`, `Need info`, `Approved`, `Rejected`

Это поле не меняет роли: PM всё равно принимает решения, поле — лишь **сигнал** для интеграции.

---

## 4) Минимальный стандарт “хорошей задачи” (для PM)

Согласуйте и закрепите стандарт, чтобы Teammate и PM работали “в одну сторону”.

### Рекомендуемая структура описания (notes/description)
- **Резюме**: 1–3 предложения “что нужно сделать и зачем”.
- **Ожидаемый результат / DoD**: чек‑лист или явные критерии.
- **Контекст**: ссылка/фрагмент обсуждения из Rocket.Chat.
- **Критические поля**: срок, приоритет, исполнитель (или “нужны уточнения”).

В конце удобно оставлять блок “Служебно” (для трассировки), куда n8n добавляет IDs и ссылку.

---

## 5) Настройка Asana Intelligence / AI Teammates (Task Coordinator)

Важно: в разных поставках Asana UI и возможности Teammates могут отличаться. Ниже — **универсальная цель настройки**, даже если названия пунктов в интерфейсе немного другие.

### Цель поведения Teammate
Teammate должен помогать PM:

- быстро сделать резюме и DoD
- предложить `Type`, `Priority`, `due date`, исполнителя
- сформулировать 1–3 вопроса, если входных данных не хватает
- подсказать “что горит” и “что делать” по задачам с рисками

### Ограничение (human‑in‑the‑loop)
Зафиксируйте правило:

- Teammate **не должен** самостоятельно менять критические поля (срок/исполнитель/приоритет), только **предлагать**.
- Решение и изменения — только после действия PM.

### Практическая настройка (ориентиры)
1) Откройте проект “Inbox from Rocket.Chat”.
2) Найдите настройки AI/Teammates (обычно в настройках проекта или AI‑панели).
3) Включите Teammate/агента типа **Task Coordinator** (или ближайший аналог).
4) Задайте “политику”/инструкции (если доступно):
   - “Всегда предлагай резюме и критерии готовности”
   - “Если нет срока/исполнителя — предложи уточняющие вопросы”
   - “Риски объясняй по проверяемым сигналам: просрочка, близкий дедлайн, отсутствие активности, blocked, нет assignee”

Если в вашей версии нельзя задавать инструкции явно — это нормально: используйте Teammate как помощника в ручном режиме (PM инициирует подсказку).

---

## 6) Рекомендации по “ежедневному обзору” (для PM)

PM должен иметь простой ритуал:

1) Открыть “Inbox from Rocket.Chat”.
2) Отфильтровать/отсортировать:
   - не `Done`
   - due date по возрастанию
   - (опц.) `Source = Rocket.Chat`
3) Использовать Teammate, чтобы быстро получить:
   - “что горит” (2–3 причины)
   - “что сделать” (1–2 действия)

---

- [ ] Создан проект “Inbox from Rocket.Chat”
- [ ] Созданы секции `New/Triaged/In Progress/Done`
- [ ] Добавлены поля `Source`, `Rocket.Chat Link` (и опционально `Priority/Type/Blocked`)

- [ ] Teammate включён (если доступен) и используется как подсказчик, а не как автодействующий агент
